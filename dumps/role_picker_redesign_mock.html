What changed vs. current screen

1. Icon badges: 64px squares → 44px circles — the blocky 18px-radius square badges (with solid gold/mint fill + white/teal glyph) read as an older, heavier "hero card" style. Circles at 44px match the mint-circle icon language already used in the redesigned Settings identity strip and Profile tab rows.

2. Cards tightened — 18px padding + 64px icon made each card ~100px tall; new cards are ~72px. Three cards now read as one connected list instead of three separate hero blocks.

3. Tags stay, simplified — kept the gold "Ages 5–11" / muted "Requires PIN" pills (already good, already matches the badge language used elsewhere), just resized to match the tighter card.

4. Added a "Profiles on this device" section label — the current screen has zero label between the subhead and the first card; an eyebrow label ties this to the same section-label pattern now used on Settings and the Profile tab.

5. Kept unchanged: the circular logo mark, heading copy, gold accent for the Learner card, chevron, and the whole staggered fade-up entrance — none of that reads as inconsistent, only the card body needed resizing.
