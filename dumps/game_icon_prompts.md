# SalamLearn — Game Icon Prompts (Level / Game Selection)

These icons replace the emoji in the rounded icon chip on each lesson card in the stage level sheet (`destination_levels_sheet.dart`, 42×42 chip tinted with the lesson colour). There is one icon per game, reused for every session of that game.

They're matched to the Student Hub art: the Adventure Map checkpoints (palm tree, trophy), the Noor Energy crescent and the backpack nav icon. Each is a single glossy object with no frame, so it never competes with the badge medallions.

**How to use**
- Paste one prompt per generation. Each is self-contained.
- Generate all 12 in one session/model for a consistent set. If your tool supports a style reference, attach `assets/images/adventure_map/checkpoint_2.png` (palm tree) and `assets/images/adventure_map/tab_backpack.png`.
- Output: 1024×1024 transparent PNG. Export a 256×256 copy for the app. Save as `assets/images/game_icons/<file name>.png`.
- Check every result at a tiny size (shrink it to about 40px). If you can't tell what it is, regenerate.
- Paste the negative prompt too, if your tool has a field for it.

---

## Negative prompt (use with every image)

```
text, letters, words, numbers, Arabic script, calligraphy, watermark, signature, logo, frame, border, badge, medallion, circle background, square background, scenery, ground, cast shadow, photorealistic, 3D render, thin lines, tiny details, cluttered, many small objects, people, human figures, faces of prophets or companions, religious figures, blurry, cropped, off-center
```
