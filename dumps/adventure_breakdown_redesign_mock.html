What changed vs. current screenshot

1. Grid → single-column row list. The 2-col `GridView` always reserves a second column even with one adventure completed — the screenshot shows one small ring tile floating in the left half with a dead empty cell beside it. A row list fills full width regardless of item count; with 2+ items it just stacks, no orphaned cell.

2. Ring shrunk 44→40px, row is full-width instead of a fixed 1.5 aspect tile — the old tile's `aspect-ratio: 1.5` forces a short, wide box that wastes horizontal space once the grid column no longer constrains it; a row lets the text breathe.

3. Added a thin accuracy progress bar under each row — the ring already encodes % but a full-width row has room for a redundant-but-scannable bar, consistent with the roster/bar pattern already used on the Teacher dashboard.

4. A "weak" adventure (accuracy < 60%, coral ring per existing logic) would also get a small coral "needs review" tag — not shown here since this sample data is 100%, but reuses the existing weak/coral branch already in _AdventureRingCard.
