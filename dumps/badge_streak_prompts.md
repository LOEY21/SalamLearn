# SalamLearn — Badge & Streak Image Prompts

Matched to the Student Hub art: the Adventure Map checkpoints (palm tree, trophy), the Noor Energy crescent moon, and the bottom-nav backpack icon.

**How to use**
- Paste one prompt per generation. Every prompt is self-contained (style + frame + subject).
- Generate all of them in one session/model so the set stays consistent. If your tool supports a style reference, upload `assets/images/adventure_map/checkpoint_7.png` (trophy) and `assets/images/noor_energy_moon.png` with each prompt.
- Output: 1024×1024 PNG, transparent background. Save as `assets/images/badges/<file name>.png`.
- Paste the negative prompt too, if your tool has a field for it.

**Two frame families, so the Backpack tabs read as sets:**
- **Milestone badges (12):** round gold medallion with a blank ribbon.
- **Streak badges (4):** eight-pointed Islamic star (Rub el Hizb) with a small golden crescent, the same crescent as Noor Energy.

---

## Negative prompt (use with every image)

```
text, letters, words, numbers, Arabic script, calligraphy text, watermark, signature, logo, photorealistic, 3D render, realistic lighting, thin lines, flat vector without outline, gradient mesh, busy background, scenery background, ground shadow, people, human figures, faces of prophets or companions, religious figures, cross, idols, blurry, low resolution, cropped, off-center
```
