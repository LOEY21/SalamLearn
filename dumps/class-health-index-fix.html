Class Health Index should count Classroom Mode only

Right now the index is built from whatever ProgressRecords happen to have a numeric moduleId — which is every solo Student Hub lesson, not classroom activity. Hot Seat/Choral records use a non-numeric moduleId and get silently dropped instead of counted. Fix: tag records at write time and filter on that tag, not on the shape of a string.

Confirmed bug — not yet fixed Plan for review

The tag

One new field on the Hive model carries the real signal — where the record came from — instead of inferring it from string shape.

FieldTypeHive indexSet by
isClassroomMode bool field 9 defaults false; hot_seat_choral.dart passes true

Implementation

  1. Add the field to the Hive model

    New bool, defaults to false so every existing record (all Home-mode history) reads as non-classroom without a migration.

    lib/data/models/progress_record.dart

  2. Bump the adapter

    Field 9 on the existing typeId: 6 adapter — write/read the new byte, same pattern as the lessonId nullable-field precedent already in this file.

    lib/data/models/progress_record.dart

  3. Pass the flag through the repository

    Add isClassroomMode as a named parameter on writeProgress(), default false — Home mode's call site needs no change.

    lib/data/repositories/progress_repository.dart

  4. Set it true at the Classroom Mode writer

    The one call in hot_seat_choral.dart that already writes assignedByTeacher: true — add isClassroomMode: true alongside it.

    lib/ui/teacher_dashboard/hot_seat_choral.dart

  5. Filter the index on the flag, not on moduleId shape

    In the per-learner bucketing loop, skip records where !record.isClassroomMode before grouping — this also fixes the silent drop, since Hot Seat's moduleId won't need to resemble a curriculum id anymore for its accuracy/error numbers to count.

    lib/logic/teacher/teacher_providers.dart — computeClassHealthIndex()

Filter, precisely

The one line that changes inside computeClassHealthIndex's per-enrollment loop.

// before — every record with a numeric-looking moduleId counts for (final record in progress.byLearnerId(enrollment.learnerId)) { byModule.putIfAbsent(record.moduleId, () => []).add(record); } // after — only what was actually played in Classroom Mode for (final record in progress.byLearnerId(enrollment.learnerId)) { if (!record.isClassroomMode) continue; byModule.putIfAbsent(record.moduleId, () => []).add(record); }
