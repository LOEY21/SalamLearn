Tap a tab for a one-shot line draw-in. Press and hold (mouse or touch) any tab to see the line animation loop continuously until you release.

Why not a downloaded LottieFiles asset

Searched the shape of what's on LottieFiles for "line icon tab" packs — the free/CC ones are almost all filled, colorful, multi-shape animated icons (bouncing coins, filled home/gear glyphs with color fills, drop shadows). None match this app's exact look: 24×24 viewBox, 2px stroke, round caps, no fill, single accent color driven by AppColors at runtime. Importing one would either look visually bolted-on next to the other tabs, or need per-frame recoloring that Lottie's static-color JSON doesn't support without a paid/pro re-export tool.

What this mock does instead

Same visual language as your current icons (identical SVG paths, copied straight from mock_icons.dart), stroke-traced in on tap. The earlier version paired the draw-in with a simultaneous scale-pop, which was the actual cause of the "floating" look — a half-drawn icon that's also swelling in size reads as drifting, not drawing. This version leaves scale alone; only stroke-dashoffset animates, so it's a clean line-draw with no size wobble.

Hold repeats the exact same draw animation on a loop (draw out, draw back in, ~1.1s per cycle) instead of playing once — recolors with AppColors.teal/textMuted at runtime like today, no asset dependency.

In Flutter: a CustomPainter using Path.computeMetrics() to extract each sub-path's length once, then an AnimationController drawing a fraction of that length via extractPath(0, length * t) — .forward() for the tap, .repeat(reverse: true) while the finger is down for the hold-loop.
