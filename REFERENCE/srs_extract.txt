4.  Non-Functional  Requirements  (NFRs)  
NFR  Category  Requirement  Description  Performance  The  system  shall  maintain  60  to  120  FPS  rendering  during  tactile  tracing  via  Flutter's  Ahead-of-Time  compilation  to  prevent  visual  stuttering.  Storage  The  system  shall  require  a  minimum  of  500MB  of  local  device  storage  to  cache  core  educational  assets  independently  of  cloud  connectivity.  Security  The  system  shall  hash  user  credentials  locally  and  encrypt  the  4-digit  PIN  to  restrict  unauthorized  access  to  administrative  modules.  Legal  The  system  shall  restrict  telemetry  collection  from  minors  without  explicit,  logged  parental  consent  to  comply  with  RA  10173.  Usability  The  system  shall  adhere  to  ISO/IEC  25010  child  HCI  guidelines  by  utilizing  single-finger  gestures  and  avoiding  complex  multi-finger  shortcuts.  Reliability  The  system  shall  execute  offline-first  reads/writes  via  a  local  NoSQL  database  (Hive)  to  ensure  zero  data  loss  during  intermittent  network  states.
