Lesson Tile — Select Motion v2

Tap a tile: quick press-in (0.97 scale, 120ms), then a smooth 220ms cross-fade to selected color/border/shadow. Badges fade+scale in at 180ms — no bounce, no burst ring, no icon rotation. Deselect reverses the same transition instantly, nothing lingers.

Pure state-driven CSS transitions (no keyframe animation, no replay logic) — maps directly to Flutter's AnimatedContainer / AnimatedScale / AnimatedOpacity with matching curve/duration, all keyed off the same added bool. Calmer than the old elastic pop + burst + rotate version, still visibly alive on tap.
