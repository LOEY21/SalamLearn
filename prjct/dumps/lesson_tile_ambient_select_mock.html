Lesson Tile — Ambient Select

Tap a tile: pop-in once, then a constant soft breathing glow while selected. Tap again: glow stops immediately, tile returns to rest — no lingering animation.

Ambient loop is CSS-only (infinite keyframe on .added), removed the instant the class drops — no fade-out tail, no orphaned timers. One-shot pop class self-clears via animationend so it can replay on every toggle.
